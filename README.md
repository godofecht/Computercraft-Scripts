# Computercraft-Scripts

Turtle programs for the ComputerCraft Minecraft mod.

| Script | What the turtle does |
|---|---|
| `digroom.lua` | Excavates a room of a given size, handling fuel and returning when the inventory is full. |
| `farm.lua` | Walks a crop field, harvests what is grown and replants it. |
| `till.lua` | Tills a plot ready for planting. |
| `news_text.lua` | Fetches text and prints it to an attached monitor. |

## Run

Copy a script onto a turtle and run it by name.

```
> farm
```

Fuel first. A turtle with no fuel stops where it is.
